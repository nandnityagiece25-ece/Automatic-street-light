# Automatic Street Light

This project uses an LDR sensor and BC547 transistor to automatically control lighting based on ambient light conditions.

## Components
- LDR
- BC547 Transistor
- Resistor (100kΩ)
- LED
- 6V Battery

## Working
The LDR detects light intensity and switches the LED ON in darkness and OFF in daylight using transistor switching.

## Applications
- Street lighting
- Outdoor lighting automation

## ⚙️ Circuit Overview
The system uses an LDR to sense ambient light and a BC547 transistor as a switch. When light intensity decreases, the transistor activates the LED, simulating automatic street lighting.
